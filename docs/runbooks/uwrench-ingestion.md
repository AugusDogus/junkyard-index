Every distinct usable native make/model pair supplies one exact selector. A
native row with unusable required YMM remains a required rejection; no blank or

`tri_state_u_wrench_and_save`, both year filters null, language `en` and explicit

The API is fallible identity enrichment. A native stock absent from the complete
successful allowed query union remains an explicit unavailable-identity
rejection. It is not inferred sold or removed. Same-owned API-only stocks lack

rejections and retain independently valid VIN/serial presence, without emitting
canonical donors. Foreign owner/site, conflicting native year, malformed

## Cursor, requests and recovery

The source has `start`, `scan`, `verify` and `complete` phases. The cursor stores
one whole parsed API record per stock and its first query, contiguous scan
membership/byte-hash/stable-hash receipts, then a contiguous verification hash
prefix. Each resume reconstructs every prior query through the existing strict
public parser and rechecks native bindings and classifications before progress.
A canonical checksum binds all persisted fields, including raw `daysInYard`;
only stable comparison omits that clock-derived field. Checksums detect trusted
state corruption and do not authenticate arbitrary rewritten cursors.

Wire cursors omit `source`. Both parse and serialize enforce 1 MiB, with the raw
byte check before JSON parsing. Current peak saved wire is 552,109 bytes across
budgets 1, 3 and 16. No second-pass response bodies are duplicated in the cursor.

Every selector is read again in a bounded verification phase. Only after all
verification and four closing context reads agree does the source emit one
native-order batch and the yard. Paused gathering/verification chunks have zero
accounting and no batch callback. The terminal chunk returns the full classified
union: 1,133 processed, 1,121 emitted and 12 rejected. Callback/read/control/budget
failure returns no advanced checkpoint; prior accepted inventory stays intact.
Complete cursor replay makes no requests or callbacks.

Chunks permit 1 through 16 selectors, default 16, plus four opening contexts and
four final closing controls, at most 24 actual requests. Use the shared provider
gate at 1,600 ms, no retries, redirect `error`, 20-second HTTP/body limits, complete
HTTP 200 with exact MIME/no range, a 4 MiB body cap and three-minute chunk cap.
The four contexts are root, native inventory, public yard info and API analytics.
`scripts/soak-uwrench.ts` drives at most 4,000 scan/verification selectors without
performing inventory writes itself.
