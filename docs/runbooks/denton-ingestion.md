The preserved AD80068 destination failure remains quarantined and was never retried. Its valid VIN and both conflicting VIN groups remain presence evidence, protecting prior records during reconciliation. Missing optional metadata remains null. The source retains the 10% rejection, 25% duplicate, 50% previous-count and 765-donor minimum guards. They run over the whole union, so a few broken model pages can stay within them. The model cards read this run, each model counted only up to its own badge, must therefore cover at least 95% of the opening model badge sum, or the run stages nothing and keeps the last accepted census. The qualification graph covered 99.5% (no page exceeded its badge), and emptying any one sixth of its model pages (measured on the six key-hashed groups the retired sweep used) drops coverage to between 77% and 87%, so one broken day fails. While the last accepted run is under 6 days old, the read cards must also cover 97% of the cards the last accepted census held for every model, each reference lowered by any drop in that model's badge (the shared replay floor). Cutting any one of those sixths of the qualification graph to a single card per model leaves between 79.3% and 89.4% of those cards (and between 78.9% and 88.9% of the badges), so that breakage fails on its first day too.

Each run reads the about, contact and make directory pages, every make menu at its slash URL (one GET instead of the native 301 plus 200), and the arrivals page. It then reads every model page on every run. Nothing is carried: an unchanged badge proves nothing about the cards under it, because a donor crushed and another placed under the same model keeps the badge, so badge-only reuse (the earlier sweep slices and six-day carry) was removed. The census still labels each read: `cold` without a usable census, `gap` after a missed, failed or rejected run, and otherwise `new`, `count` (its menu badge changed), `trigger` (an arrival under it is missing from its last accepted page), `short` (its page is short and unconfirmed) or `daily`. A model is expected to list its badge plus a sticky surplus of placeholder or surplus rows, which carries across badge changes and is lowered only as [Incremental model census](model-census.md) describes. Closing re-reads about, contact, the make directory and every model read this run whose card count differs from its badge or falls below its expected cards, and stops the run if any of them changed, so a short page that does not repeat is never accepted. A page below its badge is stored as confirmed only when its closing re-read matched in a normal incremental run (an accepted census from the same day or the day before); cold, gap and outage full reads confirm none, so the next run reads their short pages again (see [Incremental model census](model-census.md)); a confirmed page is read on the next run as `daily` (closing skips it while it repeats its confirmed evidence and re-reads it once it changes), and any other page below its expected cards is read again as `short`. Per-model changes after a page's read during a run surface on the next run's read. A missing, unreadable or incompatible previous census reads every model page.

The shared rules (read reasons, short-page confirmation, closing reads, both coverage floors and the outage path) are in [Incremental model census](model-census.md).
