# Wrench-A-Part media and outbound links

Verified September 16, 2026 against the public website and API, starting at
`b79e8ba`.

## Verdict and route evidence

- **Photos pass:** the transform preserves the API's actual vehicle `photo`.
  The live catalog contained 11,460 vehicles, 9,235 with photos, all on
  `storage.googleapis.com`. There were zero thumbnail-only records.
  The website's `/js/wrench-www.es.js` reads the same `/v1/vehicles` endpoint.
  Its photo schema explicitly says `photoThumb` is never set when `photo` is
  null. No evidence of photos discarded by our decoder or transform was found.
- **Outbound links fixed:** every record previously linked to
  `https://wrenchapart.com/vehicle-search.html`, which redirects to
  `/vehicle-search` and opens all 11,460 vehicles without selecting a vehicle.
- The public sitemap includes `/vehicle-browser.html`. Following its real
  anchors gave `/vehicle-browser/ford`, `/vehicle-browser/ford/mustang`, then
  `/vehicle-browser/ford/mustang/2000`. That page's Austin stock `AWAP084171`
  has a **More info** anchor to `/vehicle-info/1FAFP4044YF153043`.
  This is the provider's direct vehicle route, not a guessed query parameter.
- Search UI row clicks only open an in-memory modal and do not change the URL.
  Its `locationId/makeId/modelId/year` URL builder targets
  `my.wrenchapart.com`, which is a notification sign-in page, not inventory.
