# Yard names and vehicle photos

Audit: November 18, 2026. Production was read explicitly from the primary `.env`, not Bun's development `.env.local`. No production data or Algolia records were changed during this audit.

## Yard names

Across 386 live yards and 65 sources, 30 raw names equal their city and 12 are shorter than eight characters. All are `pullapart`. All 35 `pullapart` names omit the business, including five regional names such as Atlanta South. Production has operator metadata for all 35: 32 Pull-A-Part and three U-Pull-&-Pay. No other source has a city-only or short name, or a raw name different from its stored business name. The other 351 names were inspected for missing businesses; city-prefixed businesses such as Biloxi Auto Recycling are valid.

`YardName.resolve` is shared by yard details and canonical projection. Search publication reads the same yard metadata as the homepage and yard pages, once per batch. New Pull-A-Part ingestion uses `siteTypeID` for the operator. Legacy records without metadata can use the existing provider destination's host; otherwise the existing combined-brand fallback is retained. Independent businesses retain their names.

Search schema version 6 makes the existing in-place search-index migration rewrite existing records using metadata. It does not require `scripts/sync-algolia.ts`. Search-backed alerts inherit the resolved `locationName`. The ordinary next ingestion updates stored Pull-A-Part names and newly extracted photos through reconciliation. Photo backfill requires that ingestion, since an index migration cannot recover photo URLs that were previously discarded before database storage.

## Validation and retained evidence

Newly extracted photos require HTTPS, the verified provider host, an expected image path and no credentials, URL query/fragment, logo or missing-image marker. Hollander's misleading `alt="no image found"` is also present on real photographs, so the validated asset path determines whether it is a photo.

The reported AA Auto Salvage Volvo, VIN `YV1LS56D6X2572228`, stock `240419`, is present in the committed Hollander card fixture with `https://d1vnbry5hm94g5.cloudfront.net/AAE/EXY/7VQ/SSX/C-T.jpg`. A serial live GET returned HTTP 200 `image/jpeg`. Representative Midway, TriTown and Al's assets also returned HTTP 200 `image/jpeg`.

Existing Hollander, Midway Tulsa, Beaver's and Al's fixtures are reused. Added fixtures retain the actual Muncie catalog and TriTown AJAX page. New regression tests verify VIN/photo association, canonical mapping, operator metadata projection, same-code yards from different sources, legacy fallback, and rejection of unsafe or placeholder assets. Live research captures remain only under this worktree's `.scratchpad/` during implementation; no owner/project identifiers were sent in requests.
